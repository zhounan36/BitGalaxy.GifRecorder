# BitGalaxy.GifRecorder

轻量级 Windows GIF 录屏工具，纯 Rust 编写。

单文件绿色 EXE，无安装、无运行库依赖、无 Electron/.NET/WebView —— 录制 → 编辑 → 导出，一站完成。

## 功能特性

### 录制

- **灵活选区**：默认录制整个虚拟屏（支持多显示器），或全屏拖拽框选任意区域（最小 16×16）
- **帧率可选**：8 / 10 / 12 / 15 / 20 / 25 / 30 FPS
- **输出缩放**：100% / 75% / 50%（HALFTONE 高质量插值）
- **开始倒计时**：可选 3-2-1 倒计时，留足时间把鼠标移到位
- **智能跳帧**：画面无变化的帧自动合并延时，静态画面不浪费体积
- **双保险上限**：单次最长 10 分钟或帧缓存 2 GB，超出自动收尾进编辑器

### 录制可视化（全部"不入镜"）

- 红色脉冲边框画在录制区域**外侧**，永不进入 GIF
- 悬浮控制条实时显示 REC 状态、时长、帧数、体积，可随时停止/取消
- 全屏录制放不下控制条时自动隐藏，改用托盘气泡提示

### 全局热键

| 热键 | 功能 |
|------|------|
| `F9` | 开始 / 停止录制 |
| `F10` | 取消录制（自动清理临时文件） |

### 录后编辑器

- **预览播放**：播放/暂停（空格）、逐帧步进（←/→）、跳首末帧（Home/End）、循环播放
- **时间轴剪切**：48 帧缩略图 + 双把手拖拽选择导出区间
- **画面裁切**：预览区直接拖拽橡皮筋框，实时显示宽高
- **变速导出**：设置目标时长（0.1–600 秒），过度加速自动抽帧（延时摄影效果）

### GIF 编码（自研管线）

- 八叉树颜色量化（256 色全局调色板）
- Floyd–Steinberg 误差扩散抖动
- 帧差分编码：只写变化包围盒补丁，进一步压缩体积
- 无限循环输出

### 其他

- 系统托盘常驻：最小化到托盘不影响录制，explorer 重启后自动恢复图标
- Per-Monitor V2 高 DPI 完整适配，高分屏不糊
- 中文原生 UI

## 系统要求

- Windows 10 及以上（x64）
- 无需安装任何运行库

## 快速开始

1. 运行 `bitgalaxy_gifrecorder.exe`
2. 点击「选择区域...」框选录制区域（不选则录制全屏）
3. 按 `F9`（或点击「开始录制」）开始，录制完成后自动进入编辑器
4. 预览 → 剪切/裁切/变速 → 「导出 GIF」保存

## 从源码构建

需要 Rust（edition 2024，建议 1.85+）和 MSVC 工具链。

```powershell
cargo build --release
```

产物为单文件 `target\release\bitgalaxy_gifrecorder.exe`（图标、清单、版本信息已通过 Windows 资源嵌入）。

运行测试：

```powershell
cargo test
```

## 技术架构

```
┌─────────────────────────────────────────────────────┐
│ UI 线程（main.rs）                                    │
│ 主窗口 · 选区窗口 · 热键 · 托盘 · 编辑器（editor.rs） │
└──────────────┬──────────────────────────────────────┘
               │ PostMessage
┌──────────────▼──────────┐   ┌───────────────────────┐
│ 录制线程（recorder.rs）   │   │ 导出线程（export.rs）    │
│ GDI 抓帧（capture.rs）    │   │ 量化 → 抖动 → 帧差分     │
│ 帧差分 + RLE 无损压缩     │──▶│ → gif crate 编码       │
└──────────────┬──────────┘   └───────────────────────┘
               │ 流式写入
        ┌──────▼──────┐
        │ BGRC 帧缓存  │（cache.rs，自研无损格式，
        │  %TEMP% 下   │  支持随机跳帧解码）
        └─────────────┘
```

| 模块 | 职责 |
|------|------|
| `src/main.rs` | 入口、主窗口、选区、热键、录制状态机 |
| `src/capture.rs` | GDI 屏幕捕获（CAPTUREBLT 含分层窗口） |
| `src/recorder.rs` | 录制线程：固定节奏抓帧、无损压缩落盘 |
| `src/cache.rs` | 自研 BGRC 帧缓存格式（关键帧 + 差分帧） |
| `src/editor.rs` | 编辑器：预览 / 时间轴剪切 / 裁切 / 变速 |
| `src/export.rs` | 导出管线 |
| `src/gif.rs` | 八叉树量化、FS 抖动、帧差分（含单元测试） |
| `src/overlay.rs` | 红框 / 蓝框 / 控制条 / 倒计时覆盖层 |
| `src/tray.rs` | 托盘图标与菜单 |

**录制/编码分离**：录制路径只做无损搬运，量化与编码推迟到导出侧 —— 录制期 CPU 占用低，且同一段录制可反复以不同参数导出。

**运行时依赖仅 2 个 crate**：[windows](https://crates.io/crates/windows)（Win32 API 绑定）与 [gif](https://crates.io/crates/gif)（GIF 容器与 LZW），量化/抖动/帧差分/RLE 均为本项目实现。

## 已知限制

- 屏幕捕获基于 GDI，独占全屏的 D3D 游戏画面不保证捕获
- 热键固定为 F9/F10，暂不支持自定义
- 无配置持久化，帧率/缩放等选项每次启动恢复默认
